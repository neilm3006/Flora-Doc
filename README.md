# 🌿 THE FL🏵️RA DOC🩺  
A smart plant disease detection web app that uses AI models to analyze plant leaf images and recommend suitable treatments.

### 🔗 [FLORA-DOC Live Web App](https://neilm3006.github.io/Flora-Doc/)

---

## 🧠 Features

- 🌱 Select from multiple plant-specific ML models (e.g., Tomato, Potato, Bell Pepper, etc.)
- 📷 Detect plant diseases using live webcam or uploaded images
- 💧 Set soil moisture range to optimize irrigation
- 🌙 Light and Dark mode toggle
- 🎨 Smooth and responsive UI for both desktop and mobile
- 🧪 Trained on nearly **35,000 images**, including **augmented data** for improved robustness

---

## ⚠️ Accuracy Notice

- 🧬 **Models for crops like Tomato, Potato, and Bell Pepper have significantly higher accuracy**, thanks to larger, high-quality training datasets.
- 🌿 Other plant models may have reduced accuracy due to limited training data — **these are actively being improved in future versions.**
